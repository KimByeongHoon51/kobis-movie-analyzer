# KOBIS 영화 흥행 분석기

영화관입장권 통합전산망(KOBIS)의 일자별 통계 파일을 올리면 흥행 추이, 손익분기점, 매출 전략을 분석해 주는 웹앱입니다.

**[웹앱 바로가기](https://kimbyeonghoon51.github.io/kobis-movie-analyzer/)**

- 서버 없이 브라우저에서 파일을 읽어 처리합니다.
- 영화를 최대 8편까지 비교할 수 있습니다.
- 처음 열면 기본 데이터로 '왕과 사는 남자'가 표시됩니다.

## 사용 방법

1. KOBIS에서 영화의 일자별 통계정보 `.xls` 파일을 내려받습니다.
2. 웹앱의 업로드 영역에 파일을 끌어다 놓거나, 클릭해서 선택합니다.
3. 탭을 옮겨 가며 결과를 확인합니다. 손익분기 분석에는 총 제작비(억원) 입력이 필요합니다.
4. 필요하면 분석 결과를 CSV로 저장합니다.

## 분석 화면

| 탭 | 내용 |
|---|---|
| 주차별 관객 | 주차별 관객수 비교, 정점 주차와 급감 구간 |
| 누적 추이 | 누적 관객수 비교, 4주차·8주차 달성률, 흥행 완결성 |
| 스크린 효율 | 좌석판매율, 평균 스크린수, 스크린당 관객수, 평균 순위 |
| 흥행 분석 | 종합 흥행 점수, 최종 관객 예측, 흥행 패턴과 인사이트 |
| 손익분기점 | 손익분기 관객수와 도달 시점, 수익, ROI |
| 매출 전략 | 티켓 가격, 부대수입, 마케팅, 투자 회수, 시간대 편성 제안 |

## 분석 기준

- **와이드 개봉일:** 스크린 수가 최대치의 15% 이상이 된 첫날을 1일차로 봅니다.
- **재개봉 감지:** 상영 기록이 30일 이상 끊기면 구간을 나누고, 관객이 가장 많은 구간을 분석합니다.
- **최종 관객 예측:** 주간 관객 증감률의 가중평균을 쓰는 지수 감쇠 모델로 이후 주차를 추정합니다. 최근 주차에 더 큰 가중치를 둡니다.
- **손익분기점:** 티켓값에서 부가세 10%와 영화발전기금 3%를 제외하고, 배급사 몫 50%에서 배급수수료 10%를 차감해 계산합니다.
- **종합 흥행 점수:** 손익분기 달성률 50%, 좌석판매율 30%, 롱런 지수 20%를 합산합니다. 제작비를 입력해야 계산됩니다.

## 기술 스택

- React 18
- Vite 6
- Recharts
- GitHub Pages (`gh-pages`)

## 로컬 실행

```bash
npm install
npm run dev
```

GitHub Pages 배포는 다음 명령으로 합니다.

```bash
npm run deploy
```
